# Contributing

Thanks for your interest in the AI Immigration Assistant.

1. Open an issue first for anything larger than a small fix, so we can agree on the approach.
2. Fork the repo and create a branch from `main`.
3. Copy `.env.example` to `.env.local` and add your own keys. Never commit real keys.
4. Run `npm run lint` and `npm test` before opening a pull request.
5. Keep pull requests focused on one change and describe what you tested.
